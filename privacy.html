隐私政策 (Privacy Policy)

生效日期：2026年1月1日 · 最近修订：2026年10月

在流量光 (LiuLiangGuang)，我们深知数字隐私是每一位互联网使用者的基本权利。本隐私政策旨在向您详尽透明地阐明我们如何处理和对待用户数据。请您放心：我们构建流量光的核心准则就是彻底保护您的隐私，杜绝任何对用户网络行为的窥探。

【核心承诺：严格的零使用日志政策 (Strict No-Logs Policy)】
流量光绝不收集、绝不记录、绝不存储、绝不监控任何用户的上网行为数据、访问网页记录、DNS查询解析请求、通信报文内容或用户真实的公网IP地址。

1. 我们绝不收集的数据 (What We Do NOT Collect)

当您连接到流量光的任何节点服务器时，我们的网络服务器系统配置在代码级别就已完全关闭了日志记录功能：

  • 无浏览历史记录：我们不会记录您访问了哪些网站、下载了哪些文件或使用了哪些具体的移动应用。
  • 无目标流量记录：我们不会记录任何流经服务器的数据包目的地 IP 地址、端口或请求头信息。
  • 无 DNS 查询日志：所有的域名解析请求均通过专线直连的内网无痕递归 DNS 服务实时处理，完全不落地存储。
  • 无真实 IP 关联：我们不会将用户的账号身份与建立连接时的客户端公网真实 IP 进行任何持久化绑定存储。
  • 无通信明文拦截：全链路采用高强度端到端加密，即便在服务器中转层面，也绝不进行任何形式的深度数据包检查（DPI）或解密。

2. 内存无盘服务器架构 (RAM-Only Infrastructure)

为从技术根本上保障零日志政策的绝对落地，流量光全球所有加速节点均已升级部署为 RAM-Only 纯内存无盘运行架构：

  • 服务器操作系统与转发程序仅在易失性内存（RAM）中加载运行，没有任何物理机械硬盘或持久化 SSD 挂载用于存储日志数据。
  • 任何网络元数据在数据包完成转发传输后立即随内存释放而彻底覆灭。
  • 一旦发生机房硬件断电、系统重启或硬件被物理拔离，内存中的所有临时运行时数据将瞬间被清空且不可物理恢复。

3. 仅保留的必要运维账户信息

为了保障用户正常登录系统并完成套餐计费，我们仅在用户中心主数据库中保留维持账户正常运作所必需的最小化数据：

  • 账户识别信息：用户注册时自行填写的电子邮箱地址（用于登录身份验证与密码找回）。
  • 订阅与计费状态：已购套餐类型、到期时间、本周期累计已消耗的流量总额度（仅为累计字节数字，不包含任何去向内容）。
  • 支付交易凭证：由第三方支付网关生成的匿名订单流水号，流量光系统绝不接触亦不保存用户的银行卡号、CVV 码或支付密码。

4. 数据安全与加密防护

我们采用当前国际公认的工业级安全技术防范任何未经授权的访问、泄露或篡改：

  • 所有传输通道强制采用 AES-256-GCM、ChaCha20-Poly1305 等下一代前向保密（PFS）高强度加密标准。
  • 控制面板与 API 通信全量强制开启严格的 HTTPS / TLS 1.3 传输加密。
  • 内网运维采用最小特权原则与基于硬件密钥的双因子身份认证（2FA）。

5. 隐私政策的更新

随着网络安全技术的迭代与全球数据合规要求的提升，我们可能会适时更新本政策。重大变更将在官网首页醒目位置公布。若您对本隐私政策有任何疑问或安全反馈，欢迎随时通过客户支持工单与我们联系。
